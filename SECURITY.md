# Security policy

## Supported versions

Until Nodus reaches a stable release, security fixes are provided for the latest version on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose user notes, credentials or devices.

Use GitHub private vulnerability reporting for this repository. Include the affected version, reproduction steps, expected impact and any suggested mitigation. You should receive an acknowledgement within seven days.

Never include real vault contents, bot tokens, synchronization tokens or Git credentials in a report.
